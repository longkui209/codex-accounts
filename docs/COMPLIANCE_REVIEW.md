# 功能合规与公开发布审查

审查日期：2026-10-25。范围：0.14.0 源码、构建/安装脚本、接口、原生适配与发布流程。结论：**维护者选择公开完整实验源码并披露风险；正式产品合规确认和 Codex for Open Source 申请暂缓。**

本报告区分源码事实、风险判断和未验证项，不是官方许可、法律意见或独立渗透测试。审查不登录真实账号、不控制用户网页、不消耗模型额度、不使用重置卡、不重装机器组件、不改变现有运行设置。

## 依据

以上不是认定每项必然违规或必然被拒，而是目前证据不足以标记正式产品发布通过。维护者接受风险与获得服务许可是不同结论。

存在可研究的正式接入路线，详见 [官方路径差异](SUPPORTED_INTEGRATION_PATH.md)。不能把“第三方接入、多账号管理”一概描述为不支持；本报告审查的是当前具体实现。C-06 是申请材料的证据缺口，不是要求公开前先有公开用户的循环条件。

## 技术和隐私控制

源码可见 DPAPI CurrentUser、私有 ACL、固定 HTTPS 上游、禁止自动重定向、用户手动登录、限定调用者、确认/回滚/撤销及未知结果状态、禁止部分输出后重放、禁止自动使用重置卡等控制。合成检查只证明其覆盖的技术行为，结果见 `VALIDATION.md`，不构成全量安全认证。

剩余边界包括同用户恶意软件/管理员、登录暂存明文、托管字符串/崩溃转储、头像外部请求、整机规则、内部接口和原生版本变化、真实额度耗尽及多用户覆盖缺口。

## 本次整理

增加许可证和来源说明、安全/隐私/贡献文档、双语介绍、真实兼容性概要、隔离验证入口和源码清单。导出拒绝链接、账号文件、日志、运行文件与疑似令牌，仅记录相对路径、规则、行号和哈希。公开规则与概要替代本机历史指令及原始诊断。

`release/review-status.json` 分别记录实验源码公开、正式产品发布和活动申请状态。维护者在看到完整功能与风险后选择 `source-preview`，保留全部实现并公开报告；未决项继续存在。正式产品发布导出仍拒绝未通过条件。没有为让材料好看而删除现有功能，也没有更新当前运行版本。**整理、公开和审查完成不等于当前功能已获正式许可。**
