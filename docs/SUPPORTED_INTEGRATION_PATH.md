# 官方订阅接入路径与当前实现的差异

2026-10-25 核对的官方文档明确提供面向开源/本地应用的 [ChatGPT plan usage](https://developers.openai.com/siwc/token-sharing-open-source)，并描述[多账号选择及会话](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions)。**不能将多账号管理本身判为不被支持。** 允许范围与注册、授权和接口契约有关，不能从功能名称推定当前实现已满足它们。

| 项目 | 官方预览路径 | 当前源码差异 |
| --- | --- | --- |
| 应用注册 | 应用注册获发与用户/工作区绑定的客户端标识，并保存稳定、不含个人信息的主机标识。 | 主要导入官方 CLI 登录缓存并使用已有客户端标识；未实现自有动态注册记录。 |
| 授权与身份 | 用户浏览器授权，校验令牌身份和实际授予权限；各注册的客户端标识与令牌分别保存。 | 登录由官方 CLI 完成；缓存解析不等于本应用独立校验注册、身份与计划使用授权。 |
| 多账号 | 支持选择已保存注册或注册其他账号；不同注册不能因邮箱相同而合并，不能混用客户端和令牌。 | 当前标识以缓存身份为主，需按正式注册语义重新设计并迁移，不能直接宣布兼容。 |
| 模型请求 | 使用正式 Responses 路径并遵守预览请求、模型、工具及历史约束。 | 当前转发原生桌面的 `backend-api/codex` 请求，保留原生工具；不是相同接入契约。 |
| 用量 | 官方会话文档指向 ChatGPT 的 Usage 设置。 | 当前读取内部用量、模型和重置卡接口；未找到这些接口的第三方开放依据。 |
| 原生客户端 | 这些文档描述第三方应用的接入，不等于允许改写官方桌面输入逻辑或启动行为。 | 当前原生适配、机器启动、本地复制仍须单独处理。 |

[预览限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)表明此路径的工具、输入及续接行为有明确边界。迁移后是否仍能满足“保留全部原生桌面功能、远程连接、自动轮换”的现有目标，需要重新设计和真实验收，不能仅替换接口地址或模型名称。

建议后续以自有注册和手动账号选择为受支持接入候选，再逐项处理用量展示和原生兼容。额度耗尽后的自动跨账号接续不因存在账号选择器文档就自动获得许可。当前仅完成差异审查，没有擅自迁移真实账号、降低现有功能或将此路线标记为已实现。
